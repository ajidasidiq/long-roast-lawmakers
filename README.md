A single satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF — written by a small Python program that carries the line in its code and writes it to `/output/entry.txt`. The roast sets up the lawmakers' authority (a 400-page law to govern artificial intelligence) and undercuts it with the file they cannot convert: the bill itself, still waiting on the intern to turn it into a PDF.

## Run it

```sh
python3 main.py
```

This writes the one-line roast to `/output/entry.txt` (123 characters, UTF-8, single sentence).
